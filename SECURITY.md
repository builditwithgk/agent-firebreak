# Security

agent-firebreak limits the damage of prompt injection; it is not a complete defence (see the Limits section of the README).

- **Found a way around the guard?** Open a "Bypass or false negative" issue with a fictional example. This is welcome and is how the project improves.
- **A vulnerability in the library itself** (for example a crash on crafted input, or an unsafe default)? Use GitHub's private vulnerability reporting on this repository's Security tab.
