# 🔥 agent-firebreak

**Assume the model will be fooled. Limit what a fooled model can do.**

Pick an attack, and watch the same simulated worst-case agent run with and without the guard. Everything runs in your browser (Python via Pyodide); nothing is sent anywhere unless you opt in to the experimental bring-your-own-key mode.

- **Source & docs:** https://github.com/builditwithgk/agent-firebreak
- `pip install agent-firebreak`
